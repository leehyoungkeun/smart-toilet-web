# 스마트 공중화장실 — 공개 웹

지자체 공중화장실 키오스크 서비스의 **브라우저에서 열리는 페이지 두 개**만 담은 저장소입니다.

| 경로 | 쓰는 사람 | 하는 일 |
|---|---|---|
| `/` | 시민 | 키오스크 화면의 QR 을 찍으면 열린다. 동의 후 무상 생리용품 지급 |
| `/console/` | 운영자·지자체 담당자 | 화장실 현황·민원·재고 관리 |

## 왜 본체와 분리되어 있나

키오스크 앱과 운영 스크립트가 든 본 저장소는 비공개입니다. 서버 구성과
운영 절차가 담겨 있어 공개할 수 없습니다.

그런데 GitHub Pages 는 무료 플랜에서 **공개 저장소만** 호스팅합니다.
본체를 비공개로 돌리자 시민용 QR 페이지가 통째로 404 가 됐습니다.

그래서 **실제로 공개되어야 하는 것만** 이 저장소로 뺐습니다. 여기에는
서버 주소도, 운영 스크립트도, 비밀값도 없습니다.

## 여기 든 키는 안전한가

두 페이지 모두 Supabase 접속 정보를 담고 있는데, `sb_publishable_...` 는
**브라우저에 노출되는 것을 전제로 발급된 공개 키**입니다. 실제 접근 통제는
서버의 RLS 정책이 합니다. 이 키만으로는 남의 지자체 데이터를 읽을 수 없습니다.

비공개로 다뤄야 하는 `service_role` 키는 이 저장소 어디에도 없습니다.

## 배포

`master` 에 푸시하면 GitHub Pages 가 자동 반영합니다.
커스텀 도메인은 `CNAME` 파일로 지정합니다 — 호스팅을 옮겨도 주소가
바뀌지 않게 하려는 것입니다. 키오스크 앱이 QR 주소를 빌드 시점에 박기
때문에, 주소가 바뀌면 전 기기 재배포가 필요합니다.

## 원본

두 페이지의 원본은 비공개 본 저장소의 `docs/claim/`, `docs/console/` 입니다.
**고칠 때는 본체를 고치고 여기로 복사**하세요. 여기서 직접 고치면 갈라집니다.
